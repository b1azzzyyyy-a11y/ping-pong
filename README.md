# Пинг-понг

`game.py` — простая игра для двух человек на Pygame.

## Файлы

- `game.py` — весь код игры.
- `assets` — папка с картинками.
- `background.png` — фон игрового окна.
- `paddle.png` — изображение ракетки.
- `ball.png` — изображение мяча.

## Что есть в коде

Размер окна задан переменными `win_width` и `win_height`.
Окно получается размером 700 на 500 пикселей.
В программе есть один класс `GameSprite` без наследования.
Он используется для обеих ракеток и мяча.
При создании объекта загружается и уменьшается его картинка.
Координаты объекта хранятся в `self.x` и `self.y`.
Метод `reset` рисует объект по этим координатам.

После класса отдельно загружается фон.
Потом создаются `player1`, `player2` и `ball`.
Скорость мяча хранится в `ball_speed_x` и `ball_speed_y`.
Для надписи о победе заранее создаются два текста.

## Игровой цикл

Цикл `while run` выполняется, пока открыто окно игры.
Сначала программа проверяет событие закрытия окна.
Когда `finish` равно `False`, партия продолжается.
`W` и `S` двигают левую ракетку вверх и вниз.
Стрелки вверх и вниз двигают правую ракетку.
Каждый кадр координаты мяча меняются на его скорость.
У верхней и нижней границы меняется скорость по вертикали.
У левой ракетки мяч начинает лететь вправо.
У правой ракетки мяч начинает лететь влево.
Если мяч ушёл за левый край, побеждает второй игрок.
Если мяч ушёл за правый край, побеждает первый игрок.
Номер победителя сохраняется в `winner`.
После этого `finish` останавливает движение объектов.

## Что рисуется на экране

Сначала рисуется фон, затем две ракетки и мяч.
После окончания партии появляется надпись о победителе.
`display.update()` показывает новый кадр.
`clock.tick(60)` ограничивает игру до 60 кадров в секунду.
Окно можно закрыть обычным крестиком.
